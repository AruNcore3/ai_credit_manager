SDK Guides

Use Billbridge from Python and Node with clean client-style methods.

Install and first call

Python backend example
from ai_credit_sdk.client import AICreditClient

client = AICreditClient(
    api_key="YOUR_API_KEY",
    base_url="https://api.billbridge.in/v1",
)

bal = client.credits.balance()
print(bal)
Node backend example
import { AICreditClient } from "billbridge-ai-credit-sdk";

const client = new AICreditClient({
  apiKey: process.env.AI_CREDIT_API_KEY,
  baseUrl: "https://api.billbridge.in/v1",
});

const bal = await client.credits.balance();
console.log(bal);

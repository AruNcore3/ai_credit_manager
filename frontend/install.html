Install Guide

Install and import Billbridge exactly like other standard packages.

Assistant: If you can install numpy, you can install Billbridge.

Step-by-step setup

  1. Install Python 3.10+.
  2. Install package from PyPI.
  3. Import client and configure key.
  4. Call your first endpoint.
pip install billbridge-ai-credit-sdk
from ai_credit_sdk.client import AICreditClient

client = AICreditClient(
    api_key="YOUR_API_KEY",
    base_url="https://api.billbridge.in/v1",
)

print(client.credits.balance())

Env-based setup

AI_CREDIT_API_KEY=ak_live_xxx
AI_CREDIT_BASE_URL=https://api.billbridge.in/v1
import os
from ai_credit_sdk.client import AICreditClient

client = AICreditClient(
    api_key=os.getenv("AI_CREDIT_API_KEY"),
    base_url=os.getenv("AI_CREDIT_BASE_URL", "https://api.billbridge.in/v1"),
)

How should I send and rotate API keys in production?

Assistant

Header

Send key in X-API-Key for all /v1 routes.

Assistant

Key lifecycle

  • Create: POST /v1/api-keys
  • List: GET /v1/api-keys
  • Rotate: POST /v1/api-keys/{key_id}/rotate
  • Revoke: POST /v1/api-keys/{key_id}/revoke
Assistant

Security practices

  • Store keys in env vars/secret managers.
  • Never commit keys.
  • Rotate every 90 days or on exposure.
  • Deploy new key before revoking old key.

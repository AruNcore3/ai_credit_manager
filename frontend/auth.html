Auth & API Keys

Secure key usage, lifecycle operations, and production handling practices.

Header format

X-API-Key: YOUR_API_KEY

Key lifecycle

  • Create: POST /v1/api-keys
  • List: GET /v1/api-keys
  • Rotate: POST /v1/api-keys/{key_id}/rotate
  • Revoke: POST /v1/api-keys/{key_id}/revoke

Security practices

  • Store keys in secrets manager/env vars.
  • Never ship keys to frontend code.
  • Rotate every 90 days or on exposure.
  • Deploy new key before revoking old key.

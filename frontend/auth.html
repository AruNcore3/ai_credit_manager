Auth & API Keys

Secure key handling standards for production systems.

Assistant: Treat API keys like passwords. Rotate often.

Header

X-API-Key: YOUR_API_KEY

Key lifecycle APIs

  • Create: POST /v1/api-keys
  • List: GET /v1/api-keys
  • Rotate: POST /v1/api-keys/{key_id}/rotate
  • Revoke: POST /v1/api-keys/{key_id}/revoke

Practices

  • Store in secret managers/env vars.
  • Never expose in browser code.
  • Rotate every 90 days.
  • Deploy new key before revoking old key.

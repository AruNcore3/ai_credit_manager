Auth & API Key Guide

How to authenticate requests and manage keys safely.

← Back to docs home

Header

Send your key in X-API-Key for all /v1 endpoints.

Key Lifecycle

  • Create key: POST /v1/api-keys
  • List keys: GET /v1/api-keys
  • Rotate key: POST /v1/api-keys/{key_id}/rotate
  • Revoke key: POST /v1/api-keys/{key_id}/revoke

Security Practices

  • Keep keys in environment variables.
  • Never commit keys to source control.
  • Rotate keys every 90 days or immediately after exposure.
  • Deploy new key first, then revoke the old one.

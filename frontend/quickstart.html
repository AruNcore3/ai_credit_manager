Quickstart

Create tenant, get API key, and make your first production call.

Assistant: Let’s ship your first live request in 2 minutes.

1) Signup

curl -X POST https://api.billbridge.in/v1/onboarding/signup \
  -H "Content-Type: application/json" \
  -d '{"account_name":"acme","username":"owner","email":"owner@acme.com","password":"replace-me-123"}'

2) Check balance

curl -X GET https://api.billbridge.in/v1/credits/balance \
  -H "X-API-Key: YOUR_API_KEY"

3) Usage + top-up + key ops

POST /v1/usage/record
POST /v1/payments/topup-intent
POST /v1/api-keys

Self-host tutorial (download + run)

  1. Clone repository from GitHub and configure environment variables.
  2. Set up PostgreSQL + Redis (local Docker or managed instances).
  3. Run migrations and start API server.
  4. Point your SaaS backend to your Billbridge base URL.
git clone https://github.com/AruNcore3/ai_credit_manager.git
cd ai_credit_manager
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
# then call your self-hosted API
curl -X POST http://localhost:8000/v1/onboarding/signup \
  -H "Content-Type: application/json" \
  -d '{"account_name":"acme","username":"owner","email":"owner@acme.com","password":"replace-me-123"}'

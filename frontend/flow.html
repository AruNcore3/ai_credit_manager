Billing Flow Tutorial

End-to-end flow from signup to webhook credit confirmation.

Assistant: This is your golden path for reliable billing.

1) Signup

curl -X POST https://api.billbridge.in/v1/onboarding/signup \
  -H "Content-Type: application/json" \
  -d '{"account_name":"acme","username":"owner","email":"owner@acme.com","password":"replace-me-123"}'

2) Top-up intent

curl -X POST https://api.billbridge.in/v1/payments/topup-intent \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Idempotency-Key: your-idempotency-key" \
  -H "Content-Type: application/json" \
  -d '{"credits":5000}'

3) Record usage

curl -X POST https://api.billbridge.in/v1/usage/record \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"event_id":"evt_001","model":"gpt-4.1","input_token":1200,"output_token":600}'

4) Webhook confirm

Webhook endpoint:
POST /v1/webhooks/stripe

Stripe event:
payment_intent.succeeded

Result:
Credits applied idempotently to customer wallet.
